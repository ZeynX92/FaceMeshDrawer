# УТП — Расстановка ключевых точек на фотографии лица

Программа с графическим интерфейсом для автоматического обнаружения ключевых точек лица на фотографии с использованием библиотеки **Google MediaPipe**. Позволяет визуализировать 468 ориентиров лица (landmarks), настраивать внешний вид отрисовки и сохранять результат.

## Возможности

- Загрузка изображения в форматах PNG, JPG.
- Детектирование лиц с помощью предобученной модели `face_landmarker.task`.
- Отрисовка ключевых точек лица и их соединений.
- Опциональная отрисовка контуров лица (FACE_LANDMARKS_CONTOURS).
- Настройка отрисовки:
  - толщины линий соединений и контуров;
  - радиус точек ключевых точек;
  - цвет меток, соединений, контуров;
  - включение/отключение отрисовки меток и контуров.
- Сохранение обработанного изображения в файл.
- Адаптивный интерфейс на PyQt6: изображение масштабируется под размер окна.

## Установка и запуск

1. **Клонируйте репозиторий** (или скопируйте файлы проекта):

```bash
git clone https://github.com/ZeynX92/FaceMeshDrawer
cd FaceMeshDrawer
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
```

3. **Установите зависимости**
```bash
pip3 install -r requirements.txt  # Linux
pip install -r requirements.txt   # Windows
```

**Убедитесь, что папка models существует и не пуста!**

Иначе скачайте файл модели и поместите ее в models
```bash
wget -P models/ https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
```

4. **Запустите приложение**
```bash
python3 __main__.py  # Linux
python __main__.py   # Windows
```

## Инструкция по использованию
1.  ***Настроить отрисовку*** --> кнопка «Настроить обработку».
    - Укажите толщину линий (целые числа).
    - Цвета в формате R,G,B (каждый от 0 до 255).
    - Включите/отключите отрисовку меток и контура лица.
    - Нажмите «Сохранить» -- настройки применятся к следующей обработке.
2.   ***Загрузить фотографию*** --> нажмите «Загрузить фотографию», выберите файл.
3.  ***Сохранить результат*** --> после успешной обработки нажмите «Сохранить результат», выберите имя и формат
